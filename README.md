### BEASTmulch

---

#### Dependencies

To run BEASTmulch the following Quarks must be installed:

  - XML
  - wslib

```supercollider
Quarks.install("https://github.com/supercollider-quarks/XML");
Quarks.install("https://github.com/supercollider-quarks/wslib");
```

Additionally, BEASTmulchPlugins must be installed in the Extensions directory. The repository is avaiable here: `git@bitbucket.org:muellmusik/beastmulchplugins.git`.

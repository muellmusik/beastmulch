- files needed:
	squark.py
	OSC.py (from Daniel Holth)
	*.rbf (your configuration file)
- make sure the gluion is connected and transmitting data (LED is blinking)
- install Python (pre-installed on newer OS X versions, should also be default on most Linux distributions, for Windows get it here: http://www.python.org/download/windows/)


for people not comfortable with the command line:

- make sure that all the files are in the same folder 
- Mac: start the terminal: /Applications/Utilities/Terminal
  Windows: start a DOS box: [win]-r then 'cmd'
  Linux: you are comfortable with the command line
- cd into the folder with the 3 files
  (one way to get the right path is to drag it from the Finder/Windows Explorer
   type "cd " first (without the quotes but with the space) then drag)
- upload command:
  Mac/Linux: ./squark.py
  Windows:     squark.py
  (no command line options available, nor currently needed)


From there follow the menu options.

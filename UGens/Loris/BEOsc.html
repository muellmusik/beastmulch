BEOsc a Reassigned Bandwidth-Enhanced Loris Oscillator


BEOsc.ar(freq, phase, bw, mul, add )


BEOsc is similar to a normal sinusoidal oscillator, but with an additional bandwidth input, which is used to control a modulation process using filtered noise, which recreates the noisy portions of the spectrum. BEOsc accepts two special values at its phase input: -inf, meaning advance phase according to frequency, and +inf, meaning that this partial has ended and no further calculation will be necessary. Transistions from -inf to a phase value will result in a phase reset. A specially formatted Env, with phase values at onset points, inf at its end, and -inf otherwise can be used with a LorisPhaseGen to correctly control phase and maximise efficiency.

freq - Frequency in Hertz. Default value is 440.0.

phase - Phase offset or modulator in radians. Default value is 0.0.

bw - Bandwidth coefficient. 0 = a sinusoid, 1 = full bandwidth. Default value is 0.


See also: Loris, BEPartials, BEPartial, LorisPhaseGen



// what this example does

x = { BEOsc.ar(Line.ar(440, 440, 1), 0, 1, Line.ar(0.1, 0.1, 1)) }.play;

x.free;

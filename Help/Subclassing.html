Subclassing BMAbstractController


Abstract classes should contain the word 'Abstract' in their class name, e.g. BMAbstractMIDIController.


You may need to override the class method *parameterList. This should return a SymbolArray containing the user configurable arguments to the class's *new method, excluding the server argument. The default is defined like this:


*parameterList {

^this.class.findRespondingMethodFor('new').argNames.reject({|argName| 

(argName == \this) || (argName == \server)

});

}


This is useful for automatically creating configuration GUIs.

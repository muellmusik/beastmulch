BMAbstractController abstract superclass of all controllers


Inherits from: Object


BMAbstractController is the abstract superclass of all controllers in the BEASTmulch Library.


See also: BMControl


Controllers vs. Controls


The BEASTmulch provides two ways of dealing with a given control:


1) as a collection of controls - this will be a subclass of BMAbstractController and will generally represent a single hardware device and all of its controls.


2) as an individual control - an instance of BMControl.


It is sometimes useful to deal with one or the other representation depending on what one is trying to do. BMAbstractController has two classvars, allControllers and allControls, which contain dictionaries. These allow objects to query any individual control or controller by name, or to get global information about what controls or controllers currently exist.


Each controller allocates a multichannel control rate bus for its controls. Objects in the library map to controls by mapping synth Contols to the corresponding bus. Bus values are assumed to be between 0 and 1. On Cmd-. all mappings are cleared.


Creation / Class Methods


*dumpAllValues

Prints the current values of all controls to the post window. The values printed will be mapped to be between 0 and 1.

// make a controller and post its values

a = BMVirtualController(\bar);

BMAbstractController.dumpAllValues;

a.free // release its resources



*getValueByName (ctrlName)

Get the value of a control by name. This will be between 0 and 1.

ctrlName - A Symbol indicating the control's name.

// make a controller

a = BMVirtualController(\bar);

a.controlNames;

BMAbstractController.getValueByName('bar-3');

a.free // release its resources



*setValueByName (ctrlName, val)

Set the value of a control by name.

ctrlName - A Symbol indicating the control's name.

val - The value to set, between 0 and 1.

// make a controller

a = BMVirtualController(\bar);

a.controlNames;

BMAbstractController.setValueByName('bar-3', 0.5);

BMAbstractController.dumpAllValues;

a.free // release its resources

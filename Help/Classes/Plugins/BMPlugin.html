BMPlugin a plugin instance


Inherits from: Object


BMPlugin provides a general interface for making and managing monophonic plugins (i.e. processors) in the BEASTmulch library. Generally speaking these will be managed by a BMTrimPluginsRack or similar object, but they can be instantiated individually using the makeSynth and release methods. In this way they can function as resuable processing synths with automatically created GUIs.


Plugins are made using a specification object, an instance of BMPluginSpec, which provides functions for such things as SynthDef and GUI creation, standard presets, etc.


See also: BMPluginSpec, BMTrimPluginsRack, BMTrimPluginsRackGUI, BMMultichannelPlugin


Creation / Class Methods


*new (pluginSpecName, server, attributes)

Create a new plugin.

pluginSpecName - A Symbol indicating the name of the BMPluginSpec to use to create this plugin.

server - The Server to use for this plugin. Default value is nil, which results in the default server.

attributes - Plugin specs can optionally provide a set of attributes which will can serve as settings to their ugenGraphFunc, guiFunc, setupFunc, and cleanupFunc. You can pass a Dictionary or subclass here containing values to override the defaults.

// make a simple plugin

s.boot;

p = BMPlugin('Bandpass');

x = {Out.ar(1, PinkNoise.ar(0.2))}.play; // something to filter

p.makeSynth(1, x, \addAfter);

p.gui;

p.debug; // debug fun

p.attributes.dump; // see the attributes

p.release;

x.free;



Accessing Instance and Class Variables

synth

Returns this object's Synth, if it is active, nil otherwise.

def

Returns this object's SynthDef.

values

Returns an Event containing this object's current parameter values as key-value pairs.

attributes

Returns a Dictionary or subclass containing this object's attributes.

bus

Returns this object's control Bus, which is used for setting its controls.

spec

Returns this object's BMPluginSpec.

defName

Returns a String or Symbol indicating the name of this object's SynthDef.

preset

Returns a Symbol indicating the name of the current preset if there is one, nil otherwise.

server

Return this object's Server.

Instance Methods


copy

Returns a new BMPlugin which is a copy of this object.



set (key, value)

Set a control to a value.

key - A Symbol indicating the name of the control to set.

value - The value to set the control to.

s.boot;

p = BMPlugin('Bandpass');

x = {Out.ar(1, PinkNoise.ar(0.2))}.play; // something to filter

p.makeSynth(1, x, \addAfter);

p.set(\freq, 880);

p.release;

x.free;



get (key)

Get the current value of a control.

key - A Symbol indicating the name of the control to get.

s.boot;

p = BMPlugin('Bandpass');

x = {Out.ar(1, PinkNoise.ar(0.2))}.play; // something to filter

p.makeSynth(1, x, \addAfter);

p.get(\freq);

p.release;

x.free;



debug

Post the current values of all controls and then call trace on this object's Synth.



preset_ (presetname)

Load a preset.

presetname - A Symbol indicating the name of the preset to load.



makeSynth (in, target, addAction)

Make a synth for this plugin.

in - A Bus of bus index to use as the input signal to this plugin.

target - Target for this object's Synth. If target is not a Group or Synth, it will be converted as follows: If it is a Server, it will be converted to the default_group of that server. If it is nil, to the default_group of the default Server. Note: A Synth is not a valid target for \addToHead and \addToTail.

addAction - one of the following Symbols:

\addToHead - (the default) add at the head of the group specified by target

\addToTail - add at the tail of the group specified by target

\addAfter - add immediately after target in its server's node order

\addBefore - add immediately before target in its server's node order

\addReplace - replace target and take its place in its server's node order



release

Fade out and remove this plugin's synth.



gui

Open a GUI for this plugin. If a GUI func was provided in this plugin's spec it will use that one to create it, otherwise it will use the defaultGuiFunc defined in BMPluginSpec.
